# هوش مصنوعی در امنیت چندابری · AI in Multi-Cloud Security

ارائه‌ی ۲۰ اسلایدی فارسی (RTL) درباره‌ی حمله، دفاع و مهندسی عامل‌ها در ابرهای چندگانه.

A 20-slide Persian (RTL) deck on multi-cloud security: attacks, defences, and agent engineering.

---

## فایل‌ها

| مسیر | توضیح |
| --- | --- |
| `index.html` | صفحه‌ی معرفی (لندینگ): عنوان، نویسندگان، دکمه‌ی مشاهده و دانلود |
| `presentation.html` | خود ارائه — ۲۰ اسلاید ۱۲۸۰×۷۲۰، تمام اسلایدها در یک فایل |
| `assets/` | فایل‌های همراه: لوگوهای SVG، اسکریپت‌های افکت، تصویر متحرک |
| `.nojekyll` | تا GitHub Pages پوشه‌ی `assets` را بدون پردازش Jekyll سرو کند |

## اجرا

فایل `index.html` را در مرورگر باز کنید؛ یا یک سرور محلی بالا بیاورید:

```bash
npx serve .
# یا
python3 -m http.server 8000
```

برای ارائه، `presentation.html` را باز کنید و با کلیدهای جهت‌دار (یا فاصله) اسلایدها را جابه‌جا کنید.

## دانلود PDF

فایل PDF داخل مخزن نگه داشته نمی‌شود تا حجم مخزن کم بماند. دکمه‌ی «دانلود ارائه (PDF)» در صفحه‌ی معرفی، ارائه را در حالت چاپ باز می‌کند
(`presentation.html?print=1`) و پنجره‌ی چاپ مرورگر را می‌آورد؛ آنجا مقصد را **Save as PDF** بگذارید.
نتیجه همان ۲۰ صفحه‌ی ۹۶۰×۵۴۰ پوینت (۱۲۸۰×۷۲۰ پیکسل) است.
